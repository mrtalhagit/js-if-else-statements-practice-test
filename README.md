## 💻 A Look at the Concepts

**Conditional Statements**

```javascript
if (condition) {
    // Executes when condition is true
} else if (anotherCondition) {
    // Executes when another condition is true
} else {
    // Executes when all conditions are false
}
```

**Logical Operators**

```javascript
&&  // AND
||  // OR
!   // NOT
```

**Comparison Operators**

```javascript
===  // Strict equality
!==  // Strict inequality
>    // Greater than
<    // Less than
>=   // Greater than or equal to
<=   // Less than or equal to
```
